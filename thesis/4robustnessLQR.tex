\section{A Known Model}

We will start by comparing two approaches that have knowledge of the underlying model,
and can thus not need to estimate gradients, but can calculate them exactly. This allows
us to clearly seperate the benefits of a low-dimensional controller from estimation
errors.

% mb pg
Fazel et al. introduced global convergence guarantees for policy gradient methods based on the true model
in 2019 \needcite{Fazel2018Global}. It describes a method for calculating the gradient of a policy from
the system and cost matrices, and update it accordingly. As the paper uses the same u_t = -Kx_t
convention, we can implement the loop directly the following way:

% Def mb_pg
Starting from an initial, stable policy K_0 and the initial state distribution Sigma_0

% Change K to K_t to indicate temporarity

Step 1: Solving the discrete lyapunov equation \needcite{scipy}
PK = Q+ K⊤RK+ (A−BK)⊤PK(A−BK)

Step 2: Calculate state correlation matrix
    lya_a = lqr.A - lqr.B @ K_eff
    sigma_k = solve_discrete_lyapunov(lya_a, sigma_0)

bounds = np.asarray(lqr.max_initial_state, dtype=float)
return np.diag(bounds ** 2 / 3.0)

Step 3: The policy gradient
∇C(K) = 2 (R+ B⊤PKB)K−B⊤PKA ΣK

Step 4: Update the gain matrix K
K ←K−η∇C(K)

Step 5: Repeat from 1

The fixed learning rate η is a hyperparameter, which we set to 1e-05 for all inflation sizes, based on
experiments, whose results can be found in the appendix \needcite{cref to subsection in appendix}. This
policy gradient approach serves us as the basic, fully-parameterized implementation for this experiment.

% mb spi

Now we also want to implement a solver, that produces a low-dimensional controller. As in our
case the controller is characterized by the gain matrix, and for matrices dimensionality is "often
[...] expressed by the means of the rank" \needcite{Recht2010Guaranteed}, we aim at learning a low-rank
gain matrix. However, to make this comparable later to RL approaches, that rely on the number of parameters,
we define complexity for matrices the following way:

% Def
For a matrix K in R^mxn, rank k and SVD K=USigmaV', we have
U in R^mxr
Sigma in R^rxr 
V' in R^rxn

Due to Sigma being a diagonal matrix, we can store a low rank matrix with following amount of parameters

Size(K) = m * r + r + n * r = r * (n + m + 1)

Generally, this gives us the complexity as

Complexity(K) = min(rank * (q + p + 1), q * p)

so we choose the more efficient way of parameterization.

Recht et al \needcite{Recht2010Guaranteed} has already shown that nuclear norm minimization introduces
low-rank solutions for convex matrix problems. However, as we are dealing with a non-convex optimization
problem\needcite{Fazel2018Global}, we can't transfer the results over directly. Here, Park et. al 
offers us an approach to impose different structures on our policy during learning via regularizers
based on norms, one of them being the nuclear norm \needcite{Park2020Structured}. We implement the here introduced model-based
approach the following way with small adaptations:

% Def mb_spi
We reuse the loop from \needcite{def mb_pg} for calculating the gradient of the policy.

For inducing the structure, we use an adaptive learning rate combined with a linesearch criterion.

1. Set initial step size
 stepsize = 0.5 / lambda % cross check with code

2. Regularize the proximal policy
% code
  - take gradient step with the stepsize from above
  - regularize with nuclear norm

3. Check linesearch criterion
% code
- sufficient descrease condition?
- stability?

4. Return or repeat
if 3 is satisfied, return K+
otherwise stepsize = beta * stepsize and go back to 2

The learning loop can be stopped earlier if the criterion ∥Ki+1−Ki∥≤epsilon is satisfied. 

As one can see, there are a lot of parameters that can be modified here. We set epsilon to be
1e-8, and use the same beta = 0.5 as in the experiments section of \needcite{Park2020Structured}.
For lambda, as it defines the learning rate as well, we have run an experiment with various values,
which can be found in the appendix. A lambda = 5 has shown the most promising results across the sizes.

One thing that we implemented additionally is a cap on the amount of linesearch iterations, which we set to 20.
Some of our previous experiments had shown, that if we leave it uncapped, for unstable updates, which are impossible
to stabilize, the loop will run until the update produces no effect at all.

\section{Unknown Model Accross Dimensions}

Here we will take a look at the more realistic case, where we don't know the underlying model and compare different approaches.
Before we can get into the results, we first take a deeper look at the solvers that we will use and how the experiments are
set up.

\subsection{Setting}

First, we will introduce our basis for the indirect model-free approach, which is based on system identification. N4SID,
introduced by \needcite{vanoverschee}, uses "the projection of the future outputs [of the system] onto the past and future inputs
and the past ouputs"\needcite{sec 3 van overschee}. These projections are then called "a function of the system matrices and the input-output block
Hankel matrices" \needcite{sec 3, vanoverschee}, which allows us to reconstruct exactly that from the results. Important
are further the assumptions that the systems are observable \needcite{chap2} and controllable \needcite{chap2} For simplicity, we will rely on the
implementation of N4SID from Sippy Unipy \needcite{TODO}, which we integrate into our own setup. This implementation allows us to recover
the system matrices A, B and C, whereas the recovering of the cost matrices Q and R is implemented by us from scratch based on \needcite{vanoverschee}.

The collection of observation and action data is based on the following loop:

% simplify into latex code, core meaning should be randomly sampling the excitation added on top of gain
for _ in range(settings.trajectory_length):
        y = plant.observe()
        v = -K_0 @ y + settings.excitation * rng.standard_normal(plant.action_dim)

        step = plant.apply_control(v)

As mentioned in the paper, "as i grows larger, the approximation error grows smaller.", with i being dependent on the length our
trajectory described above used for identification. The other variable "j", defines the dimensions of the Hankel matrices, and thus
how far the projections reach into the future and the past. As we want to be computationally efficient, while still achieving the
best performance, we evaluated different values for both, to find the most optimal setting to use in our experiment.
The full results of the selection can be found in the appendix \needcite{section for tables/plots in appendix}. Specifically,
we will use

% Table structure, trajectory length (i), hankel horizon (j)
CHOSEN_IDENTIFICATION = {
    "base": (500, 5),
    "small": (500, 5),
    "medium": (500, 5),
    "large": (2000, 5),
}.

The resulting identified system will then serve as a surrogate for the true model
for the model-based approaches from \needcite{settings sections from known model}. This thus produces results without
ever having access to the real model.
