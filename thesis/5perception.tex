\chapter{Perception-based Experiments}\label{chap:perception}

From the previous artificially inflated inputs, we aim to move to a more realistic
example, which shows the robustness of low-dimensional controllers in a scenario involving
an image observation as input. We do this by first using our setup from the previous
chapter to scale it to a dimension, which resembles image inputs. Afterwards, we
actually build a new environment, which combines perception-based observation with
multiple actuators acting on our double integrator.

\section{Artificial Inflation to Pixel Size}

\subsection{Setting}

As mentioned, we take our loop from before \needcite{cref} and scale it up further. The input
dimension in this case becomes 18432, while the output dimension stays at 256. These numbers
were specifically selected to match the setup in \needcite{new environment}, such that we can
compare both more closely. For the input dimension, this is an 96 x 96 image stack of two images,
while for the output dimension it was chosen due to the specific construction.

We further note that PPO Encoder can not be applied at this scale, as the identification
for such large matrices is computationally impossible. Additionally, we excluded the PPO Linear
approach, as it was only used to compare with LQR approaches.

\subsection{Pos-Vel Encoder}

For this new environment we introduce another feature extractor, which is based on robotic priors used
in our Scalable Encoder \needcite{Jonschkowski2015Learning}. Called Position-Velocity Encoders \needcite{Jonschkowski2017PVE},
it tries to encode a position and velocity state from an observation, by learning a latent position state, and then
reconstructing the velocity state using temporal differences. As we specifically look for position and velocity in our
states, we can construct even more specific priors, again in line with our reasoning that knowledge about the embodiment
helps designing the controller architecture \needcite{section motivation?}. The priors used in \needcite{Jonschkowski2017PVE} are:

1. Variation - "Positions of relevant things vary"
2. Slowness - "Positions change slowly"
3. Inertia - "Velocities change slowly"
4. Conservation - "Velocity magnitudes change slowly"
5. Controllability - "Controllable things are relevant"
